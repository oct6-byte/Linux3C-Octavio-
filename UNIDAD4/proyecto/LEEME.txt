EJECUCIÓN EN LA VM (terminal de Ubuntu, no por SSH)
  1. Copiar los scripts a ~/scripts y entrar:
       cd ~/scripts
  2. DNS y sitio web (dominio: hojita.linux):
       sudo bash dns.sh
  3. Publicar esta página:
       cp index.html ~/scripts/sitio-hojita.linux/index.html
       sudo bash dns.sh --publicar
  4. SSH para root solo con llave:
       sudo bash ssh-generator.sh
     Menú 1 y luego llave 3 (archivo .pub). Si el .pub viene de Windows,
     antes quitarle el fin de línea de Windows:
       sed -i 's/\r$//' ~/llave_casa.pub
  5. Comprobar:
       dig @IP_VM hojita.linux +short
       curl -s http://hojita.linux | grep -o '<title>.*</title>'

EN WINDOWS (PowerShell como administrador)
  Set-DnsClientServerAddress -InterfaceAlias "Wi-Fi" -ServerAddresses "IP_VM"
  Clear-DnsClientCache
  nslookup hojita.linux
  Abrir en Chrome: http://hojita.linux
  ssh -i "$env:USERPROFILE\.ssh\llave_casa" root@IP_VM
  Al terminar, regresar el DNS normal:
  Set-DnsClientServerAddress -InterfaceAlias "Wi-Fi" -ResetServerAddresses
